Prepare an assignment with Merge and Split PDF

Practise page selection and document order with an original three-page sample, then check the downloaded PDF before submission.

Open Split PDFOpen Merge PDF

An assignment often needs a cover, the main work and supporting pages in a particular order. Start by checking the submission instructions: one PDF or separate files, the required page order, and the maximum size. The sample below is fictional and has a cover, a notes page and a checklist. You can practise without uploading a private document.

Download the three-page sample assignment PDF. Page 1 is the cover, page 2 is the notes, and page 3 is the checklist. All three pages use A4 dimensions. The file has ordinary searchable text; it contains no signature, official certificate or personal record.

Extract the notes and checklist

  1. Open Split PDF and choose the sample file.
  2. Enter 2-3 in Page Range Selection. The selected count should be two. You can also tap page thumbnails.
  3. Choose Extract & Save, then download the result.
  4. Open the download in a separate PDF viewer. It should have two pages: Revision notes followed by Submission checklist.

The tool outputs selected pages in their original source order. Entering 3,2,2 still produces pages 2 and 3 once each; it does not reverse their order. Use PDF Page Reorder when the pages themselves need rearranging. Ranges such as 2junk, 3-2 or 1-999 are invalid for this three-page example.

Create the cover, then merge the two files

  1. Return to Split PDF, select only page 1, and download the cover.
  2. Open Merge PDF. Choose the cover PDF and the two-page result from the first exercise.
  3. Check the file list. Move the cover above the notes/checklist file if necessary. Merge uses file order, including every page within each file.
  4. Merge and download. Reopen the result and confirm the sequence: cover, notes, checklist. There should be three pages.

What to inspect before a real submission

  • Confirm page count and order; an extra blank page can be easy to miss.
  • Zoom in on small text, diagrams, signatures and any scanned page.
  • Check form fields, links and bookmarks if you depend on them. Combining pages does not establish that every document-level interactive feature is preserved.
  • Check the resulting file size against the portal's actual limit. Merging is not compression.

If the file will not open or export

Use a valid PDF that you can open in another viewer. A password-protected file may need PDF Unlock with the correct password first. Very large documents can exceed a phone's memory; try fewer files or a desktop browser. Keep the originals so a failed or incorrect export can be retried.

Merge and Split perform this workflow in the browser. They do not turn photographed text into searchable text, and removing a page is different from removing private information within a retained page.

Found an unclear step or incorrect output?

Report it to support with the tool name, browser and the step that failed. Avoid sending private documents or passwords. These examples cover the stated workflow; they cannot guarantee every PDF, image or phone will behave identically.
