Product Updates · Updated October 2026

Changelog & Release Notes

We continuously improve OnlinePDFPro to deliver fast, reliable, privacy-conscious PDF workflows without artificial paywalls or deceptive metrics.

October 2026 — Phase 1 & Phase 2 Enhancements

1. Flagship Workflows & Direct Tool Access

  • Prioritized the top 5 core workflows directly below the homepage hero: Merge PDF, Compress PDF, Split PDF, PDF Editor, and JPG to PDF.
  • Added recommended next-step actions on completion screens (e.g., Merge → Compress, Split → Compress, Word → Word to PDF).
  • Cleaned directory and category descriptions to eliminate conflicting marketing claims.

2. Transparent Privacy Architecture

  • Introduced the 3-Tier Processing Boundary card distinguishing local client-side memory processing, ephemeral isolated server gateways, and opt-in cloud AI.
  • Clarified visual electronic annotations versus cryptographic PKI signatures in Sign PDF.
  • Clarified client-side Tesseract.js OCR vs explicit opt-in cloud OCR in Image to Text.

3. Official Downloadable Practice Pack

  • Published the non-sensitive Official Practice Pack (ZIP) featuring Word, assignment PDF, and exam hall ticket fixtures.
  • Direct fixture integration for flagship workflows: test Split PDF and Compress PDF with authentic test files.
  • Linked test fixtures directly below upload dropzones across all top 10 core search landing pages.

4. Performance & Mobile Responsive Reflow

  • Reflowed homepage and tool layouts to pass 320px ultra-compact mobile viewport audits without horizontal overflow.
  • Eliminated empty reserved advertisement spaces to guarantee zero content obstruction above the fold.
  • Maintained strict static site performance budgets under 30 MB.

5. Privacy-Safe Feedback

  • Support and issue reporting now explicitly encourages qualitative error codes and non-sensitive test fixtures, ensuring zero user document bytes or filenames are transmitted in bug reports.

Have feedback or found a bug?
