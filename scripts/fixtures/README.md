# Synthetic HEIC fixture

`synthetic.heic` is an original, generated 240 × 120 image: a red left half and a blue right half. It contains no photograph or customer data. The workflow suite runs the site's genuine bundled HEIC decoder on it and checks the exported JPEG dimensions and batch ZIP contents, alongside a deliberately corrupt input.

Generated with Pillow and pillow-heif (quality 85). Regenerate in an environment with those packages installed:

```python
from PIL import Image, ImageDraw
import pillow_heif

pillow_heif.register_heif_opener()
image = Image.new("RGB", (240, 120), "red")
ImageDraw.Draw(image).rectangle((120, 0, 240, 120), fill="blue")
image.save("scripts/fixtures/synthetic.heic", format="HEIF", quality=85)
```

Other fixtures are generated by `tool-test-harness.mjs` into the ignored `.tmp_tool_audit/` directory. They cover PDFs with rotations, nonzero crop boxes, a real text form, link/highlight annotations, encryption, raster content, and invalid inputs. No Python dependency is needed to run the committed tests.
