Frequently Asked Questions

Are my PDF files safe?

Yes, absolutely. This tool uses JavaScript to process your files directly in your web browser. Your PDF files are never uploaded to any server, guaranteeing 100% privacy and security.

Can I count pages in multiple PDFs at once?

Yes! You can select dozens of PDF files at the same time. The tool will give you a list of each file's page count along with a grand total.

Is there a limit on file size?

Since the processing happens on your device, there are no file size limits or daily usage limits. You can use it as much as you need for free.
